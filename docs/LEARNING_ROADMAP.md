# Aposma Learning Roadmap

## Before coding

Understand enough of:

1. Git and diffs
2. compiler pipeline
3. AST concept
4. static analysis
5. transformers and local inference

## While building the analyzer

Learn:

- Clang AST
- LibTooling
- AST Matchers
- source locations
- call graphs
- control-flow/data-flow basics
- false positives / negatives

## While building the evidence layer

Learn:

- structured representations
- graphs
- relevance/context selection
- JSON schemas
- grounding

## While integrating the SLM

Learn:

- tokenization
- context windows
- inference
- temperature
- structured JSON output
- hallucination
- evaluation
- quantization

## While adding GitHub

Learn:

- GitHub Apps
- webhooks
- installation tokens
- Checks API
- annotations

## While executing tests

Learn:

- processes
- sandboxing
- Docker
- timeouts
- resource limits

## Evaluation

Learn:

- precision
- recall
- false positives
- false negatives
- benchmark construction
- human evaluation
